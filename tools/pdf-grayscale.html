This tool re-renders each page as an image and embeds it in a new PDF, which can increase file size compared to the original. Use a lower quality setting to reduce the output size.
Since each page is rasterized (converted to an image), text will not be selectable in the output PDF. This is a limitation of browser-based grayscale conversion without an AI/OCR layer.
